# Интерактивный дашборд лифта

Проект подготовлен для Visual Studio Code и обычного Visual Studio.

## Структура
- `index.html` — основная страница
- `css/style.css` — стили
- `js/script.js` — интерактивная логика
- `assets/shaft-reference.png` — изображение шахты лифта

## Запуск в Visual Studio Code
1. Откройте папку проекта через **File → Open Folder**.
2. Откройте `index.html`.
3. Можно запустить двойным щелчком в браузере.
4. Для удобной разработки установите расширение **Live Server** и нажмите **Go Live**.

## Запуск в Visual Studio
Откройте папку проекта через **File → Open → Folder**.
Для статического проекта достаточно открыть `index.html` в браузере.

Интернет для работы дашборда не требуется.
